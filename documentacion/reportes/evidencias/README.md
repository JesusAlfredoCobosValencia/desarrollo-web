# Evidencias del proyecto TwoVago

**Entregable:** R2 — Backend basico y base de datos  
**Equipo:** TwoVago  
**Repositorio:** https://github.com/JesusAlfredoCobosValencia/desarrollo-web

---

## 1. Objetivo

Esta carpeta contiene las evidencias visuales de las actividades realizadas durante el segundo entregable del proyecto TwoVago.

Las capturas permiten comprobar el desarrollo inicial del backend, la configuración de Spring Boot, la conexión con MySQL, la creación de entidades y componentes de acceso a datos, así como las pruebas realizadas mediante Maven, CURL y consultas a la base de datos.

## 2. Relación de evidencias

| Archivo | Descripción |

| E2_09 | Archivo de configuración del proyecto Maven (pom.xml). |
| E2_10 | Configuración y conexión con la base de datos MySQL. |
| E2_11 | Creación de las entidades del sistema mediante JPA. |
| E2_12 | Implementación de repositorios para acceder a los registros. |
| E2_13 | Desarrollo de la capa de servicios del backend. |
| E2_14 | Implementación de controladores REST y endpoints. |
| E2_15 | Compilación del proyecto mediante Maven. |
| E2_16 | Ejecución del servidor Spring Boot. |
| E2_17 | Consulta y comprobación de registros almacenados en la base de datos. |

## 3. Organización

Las capturas se encuentran almacenadas en esta carpeta y utilizan la nomenclatura E2 para identificarlas como evidencias correspondientes al segundo entregable.

Cada imagen respalda una actividad específica del desarrollo del proyecto.

## 4. Tecnologías utilizadas

- Java 17.
- Spring Boot.
- Maven.
- MySQL.
- Hibernate / JPA.
- CURL.
- Git y GitHub.

## 5. Observaciones

Las evidencias documentan el avance de implementación del backend y la persistencia de datos de TwoVago.

Los módulos adicionales de autenticación, reservaciones y pagos simulados continuarán desarrollándose e integrándose conforme al avance del proyecto.
