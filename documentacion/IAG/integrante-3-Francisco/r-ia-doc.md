## Reporte de uso de IA

**Herramienta:** ChatGPT  
**Modelo:** GPT-6  
**Integrante:** Francisco  

### 1. Breve descripción de uso

Se utilizó IA para proponer el diseño visual inicial del frontend de TwoVago. La intención fue obtener una estructura sencilla para la página principal, utilizando HTML y CSS, manteniendo el nivel de los ejercicios realizados durante el curso.

### 2. Prompt utilizado

> Dame ideas de diseño que sea sencillo no muy complejo para la página principal de una aplicación web de reservación de hoteles, debe utilizar HTML y CSS básicos, debe tener como un encabezado, un apartado para buscar hoteles por ciudad y una sección para mostrar los resultados.

### 3. Resultado obtenido

La IA propuso una estructura visual basada en un encabezado para TwoVago, un área de búsqueda por ciudad y una sección para mostrar los hoteles encontrados. También propuso estilos básicos para el fondo, secciones, botones, campos de texto y tarjetas de hoteles.

### 4. Aplicación en el proyecto

La propuesta se tomó como referencia para desarrollar el archivo:

`frontend/css/styles.css`

El diseño fue adaptado al frontend de TwoVago y se mantuvo separado del HTML y JavaScript.

### 5. Cambios realizados

La propuesta se utilizó como base para definir los estilos generales de la página, incluyendo el encabezado, las secciones de contenido, el campo de búsqueda, los botones y la presentación de cada hotel.
