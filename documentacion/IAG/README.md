# Registro de uso de inteligencia artificial generativa

Esta carpeta contiene los registros del uso de herramientas de inteligencia artificial generativa durante el desarrollo del proyecto TwoVago.

Cada integrante debe documentar las consultas realizadas, las respuestas obtenidas y la manera en que utilizó la información proporcionada por la IA.

## 1. Estructura de la carpeta

```text

IAG/
├── README.md
├── Declaración de uso de ia firmado.pdf
├── plantilla-r-ia-dev-sxx.md
├── integrante-1-Jesus/
│   └── r-ia-doc.md
├── integrante-2-Emanuel/
│   └── r-ia-doc.md
└── integrante-3-Francisco/
    └── r-ia-doc.md
```

## 2. Tipos de registros

### 2.1. Registro de consultas: r-ia-doc.md

Este archivo documenta las consultas realizadas a herramientas de inteligencia artificial que no generan código, como solicitudes de ideas, orientación, explicaciones y apoyo para la documentación.

Durante el primer entregable, únicamente se registra una consulta realizada por Jesús, relacionada con ideas generales para el diseño de las interfaces de TwoVago.

Los archivos de Emanuel y Francisco permanecen preparados para registrar consultas futuras.

### 2.2. Registro de desarrollo: r-ia-dev-sxx.md

Este formato se utilizará en las siguientes etapas del proyecto cuando se empleen herramientas de IA para generar, modificar, depurar o probar código.

Durante el primer entregable no se registran sesiones de desarrollo con IA, debido a que las actividades realizadas corresponden al análisis y diseño del sistema.

La plantilla general se conserva para utilizarse cuando comience la implementación.
