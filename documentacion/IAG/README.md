
# Registro de uso de inteligencia artificial generativa

Esta carpeta contiene los registros del uso de herramientas de inteligencia artificial generativa durante el desarrollo del proyecto TwoVago.

Cada integrante debe documentar las consultas realizadas, las respuestas obtenidas y la manera en que utilizó la información proporcionada por la IA.

## 1. Estructura de la carpeta

```text
IAG/
├── README.md
├── Declaración de uso de ia firmado.pdf
├── plantilla-r-ia-dev-sxx.md
├── integrante-1-Jesus/
│   └── r-ia-doc.md
├── integrante-2-Emanuel/
│   └── r-ia-doc.md
└── integrante-3-Francisco/
    └── r-ia-doc.md
```

## 2. Tipos de registros

### 2.1. Registro de consultas: r-ia-doc.md

Este archivo documenta las consultas realizadas a herramientas de inteligencia artificial generativa para obtener ideas, orientación, explicaciones y apoyo en la documentación del proyecto.

Los registros se organizan por integrante y contienen la fecha, herramienta utilizada, prompt original y respuesta obtenida.

### 2.2. Registro de desarrollo: r-ia-dev-sxx.md

Este formato se utiliza cuando se emplean herramientas de inteligencia artificial para generar, modificar, depurar o probar código.

Se conserva la plantilla general para documentar las actividades de desarrollo asistidas por IA, incluyendo los prompts, respuestas, modificaciones realizadas y pruebas de funcionamiento.

## 4. Responsabilidades individuales

Cada integrante es responsable de mantener actualizado su registro individual y documentar únicamente las consultas y actividades de IA que haya realizado personalmente.

Los registros de desarrollo deberán incluir las modificaciones de código asistidas por IA y las pruebas utilizadas para comprobar su funcionamiento.
