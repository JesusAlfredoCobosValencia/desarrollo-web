# Registro de uso de inteligencia artificial generativa

Esta carpeta reúne la documentación del uso de herramientas de inteligencia artificial generativa durante el desarrollo de TwoVago.

Cada integrante es responsable de registrar las consultas que haya realizado, explicar cómo utilizó las respuestas y documentar las modificaciones o verificaciones que haya hecho.

## Estructura

```text
IAG/
├── README.md
├── declaracion-uso-ia.md
├── plantilla-r-ia-dev-sxx.md
├── integrante-01-jesus/
│   └── r-ia-doc.md
├── integrante-02-emanuel/
│   └── r-ia-doc.md
└── integrante-03-francisco/
    └── r-ia-doc.md
```

Los nombres de las carpetas identifican a cada integrante. Cada persona debe completar y mantener actualizado su propio registro.

## ¿Qué se registra?

### 1. Consultas que no generan código

Se documentan en el archivo `r-ia-doc.md` de cada integrante. Por ejemplo:

- Consultas para comprender conceptos o tecnologías.
- Análisis y revisión de requisitos.
- Apoyo para organizar documentación.
- Revisión de modelos, diagramas o decisiones de diseño.
- Explicaciones y resolución de dudas.

En cada registro se debe conservar la información solicitada por el formato del curso, incluyendo la fecha, herramienta utilizada, consulta o prompt y respuesta obtenida. También se debe explicar qué hizo el integrante con esa respuesta.

### 2. Sesiones de generación o modificación de código

Cuando se utilice IA para generar o modificar código, se debe crear un registro independiente con el formato `r-ia-dev-sxx.md`, usando la plantilla de esta carpeta.

El registro debe reflejar la sesión real: prompt, resultado generado, cambios que hizo el estudiante, commits relacionados cuando existan, pruebas realizadas y reflexión sobre el resultado.

No se deben crear registros de desarrollo de código si todavía no hubo una sesión de ese tipo.

Cada integrante debe registrar únicamente las interacciones que realizó personalmente. Si una herramienta o respuesta fue compartida por el equipo, se debe explicar esa situación sin atribuir a otra persona una consulta que no hizo.

## Declaración de uso de IA

El archivo `declaracion-uso-ia.md` contiene la declaración del equipo. Los tres integrantes deben revisarla y firmarla según las indicaciones del profesor.

## Reglas para mantener los registros

1. Registrar las consultas de forma fiel, sin inventar fechas, prompts, respuestas ni pruebas.
2. Diferenciar el apoyo documental del uso de IA para generar o modificar código.
3. Identificar qué contenido se utilizó, qué se modificó y cómo se verificó.
4. Mantener los registros actualizados durante cada etapa del proyecto.
5. Relacionar los registros con los commits o archivos correspondientes cuando aplique.
6. No incluir contraseñas, tokens, claves privadas ni otros datos de acceso.

Los registros de esta carpeta forman parte de la evidencia del proceso de desarrollo de TwoVago y deben mantenerse junto con la documentación del proyecto
