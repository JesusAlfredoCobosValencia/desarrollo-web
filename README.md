# TwoVago

Proyecto final de Desarrollo Web.

## Descripción

Plataforma web para buscar y reservar hoteles. Incluye perfiles de usuario, historial de estancias, cancelaciones y pagos simulados con tiempo límite.

## Tecnologías

- Java 17 y Spring Boot.
- Maven.
- MySQL y Hibernate/JPA.
- HTML, CSS y JavaScript.
- API Fetch.
- Git y GitHub.
- WSL.

## Estructura

- `backend`: API REST y lógica del sistema.
- `frontend`: interfaces web.
- `database`: scripts y respaldo de la base de datos.
- `documentacion`: análisis, reportes, diagramas y evidencias.
